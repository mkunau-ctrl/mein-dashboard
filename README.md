# Mein Dashboard

Private Web-App: eine Oberfläche für mehrere Lebensbereiche (Ernährung, To-dos,
Finanzen, Lager), aufrufbar auf jedem Gerät. Daten in Supabase, Login per
Magic-Link. Kein Framework, kein Build – reines HTML/CSS/JS.
